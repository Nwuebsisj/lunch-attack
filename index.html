About this website

A note on prices and updates.

Important to know

This is a static website — meaning all content (menu items, prices, hours) lives directly in the page itself. There's no admin panel or login where you can edit it yourself.

What this means for you:

  • To update a price or add a new item, just message us — we'll make the change and republish the page, usually within the day.
  • Small changes (a price update, a new menu item) are quick and straightforward.
  • Bigger changes (a new section, a redesign) are quoted as a separate project.

Prices on this page are based on publicly available menu photos and may not reflect the most current rates. Please confirm directly with the branch for the latest pricing.
